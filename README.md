## Computer System Architecture - Labs ##
Repository for ITMO CSA Labs about CPU models and architectures

### Main Contents
1) Lab 2 - Essays about actual programming topics
   - ```essay1``` - ["The Future of Programming"](lab2/essay1.docx)
   - ```essay2``` - ["Stop Writing Dead Programs"](lab2/essay2.docx)
2) Lab3 - Simple scripts implementations for different CPU models, such as:
   - ```acc32``` - ["little to big endian"](lab3/acc32/little_to_big_endian.s)
   - ```f32a``` - ["sum even n"](lab3/f32a/sum_even_n.s)
   - ```m68k``` - ["format string"](lab3/m68k/format_string.s)
   - ```risc-iv``` - ["hello user pstr"](lab3/risc-iv/hello_user_pstr.s)
   - ```scheme``` - _[f32a](lab3/scheme)_
   - ```vliw-iv``` - ["sum and sum squares"](lab3/vliw-iv/sum_and_sum_squares.s)

3) Lab4 - _[half68k](https://github.com/TheGeniusOfEternity/half68k)_
